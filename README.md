# Evan Tarot 時間流：固定管理員登入按鈕版

## 本包內容
- timeflow.html：已在時間流控制列加入固定「管理員登入」按鈕
- JS/divination-map.js：完整時間流程式，含管理員登入彈窗
- style.css：補強登入按鈕樣式

## 使用方式
把三個檔案覆蓋到 GitHub Pages 專案：
- timeflow.html → 專案根目錄
- style.css → 專案根目錄
- JS/divination-map.js → 專案 JS 資料夾

## 登入方式
進入 timeflow.html → 點畫布上方「管理員登入」→ 輸入 EVAN
