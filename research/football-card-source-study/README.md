# 足球塔羅牌源差異研究專案

專案代號：FTS-01｜版本：1.1｜建立／修訂：2026年11月7日（台灣時間）

## 研究問題與交付目標

同一位解牌者 Evan，以自己的實體牌抽牌並自行解讀時，自述準確度約75%；以網站抽牌並同樣自行解讀時，約25～50%。本專案研究差異能否重現、差異發生在哪一段，以及哪些操作能改善實際表現。75%與25～50%是研究起點，不是已重算的前向績效，也不是篩選樣本的門檻。

交付目標依序為：重建既有比較、確認數位抽牌與紀錄鏈、建立同場成對的個人前向實驗、辨認有效抽牌條件、將有效條件轉成網站與操作規格。研究技術、統計、抽牌操作、抽牌當下狀態與靈性連結，各項留下事前預測、替代解釋與會削弱它的結果。

**1.1範圍修正：兩種牌源都固定由Evan自行解讀。解讀方式、牌義推論、解牌偏誤、展示媒介如何影響解讀，暫不列為研究變項。研究焦點放在牌如何被抽出，以及抽出的牌與目標賽事的對應。這是本階段範圍設定，不宣稱已證明所有解讀因素都不存在。**

「靈性」在本專案包含人與牌的連結、意念設定、抽取決定的參與、儀式、共時性及連續問同一問題的影響。不預設這些效應已成立，也不因其難以直接量測就排除。可測的效果與對效果的世界觀解釋分開記錄。

## 固定承接的專案規則

- GitHub main 是網站程式正式來源；Google Sheets 是使用者雲端資料；Apps Script 是後端正式來源。本研究存放於獨立研究目錄，正式網站的抽牌與解牌規則沒有因建立專案而更換。
- 沿用五張：整體場域、主攻、客防、客攻、主防。牌位如何連結比賽是既有研究工作，不把它直接定性為設計錯誤。
- 沿用 V5「整體初讀→雙向攻防→事件觸發後重讀→全局回看→決定」，保存 Evan 原始解讀，AI意見另記。修改上游解讀後，受影響下游重新審閱。
- 本階段固定 Evan 自行解兩種牌源，沿用其既有解讀方式；原判只用來計分與追溯，不做解牌方式比較、牌義重審、AI改寫或來源預期造成解讀差異的測試。
- 不因網站成績較差就先換亂數、不因實體牌較準就先宣布能量差異成立。效果先重現，機制再拆解。

## 前向實驗 P1：先重現你的實際差異

### 主要比較

A＝Evan現行實體抽牌＋Evan解牌。B＝現行網站抽牌＋Evan解牌。兩者使用同一場、同一90分鐘結算、同一賽事資訊包與同版V5解讀流程。這一階段測的是兩條日常操作流程的總差異；尚未分離觸覺、儀式與放回政策。

### 每場流程

1. 開賽前先決定收錄賽事，填唯一賽事ID、主客隊、kickoff與資訊包時間。不以看完牌才決定是否納入。
2. 每次抽牌前填疲勞、專注與抽牌連結感各0～10；資訊包之外新得知的內容另記時間。兩組之間不查新賽況。不收集「來源預期如何改變解讀」問卷。
3. 使用平衡隨機順序：每4場中2場先手抽、2場先網站，區塊順序事前亂數決定。原始抽牌政策各自保留並完整記錄。
4. 第一組抽完即記五張牌與正逆位，保存drawnAt、來源與抽牌政策；不因牌不順而重抽。手抽記一次習慣流程，之後只記例外。
5. 由Evan沿用既有方法獨立解讀兩組，保存原始文字與主判H/D/A或ABSTAIN；若原本有精確比分則另存。不增加牌義評分、語義反證或解讀原因問卷；信心欄為選填。
6. 鎖定第一組後才揭露第二組；第二組仍獨立保存。不准回改第一組；修訂另開版本，首版作主要評分。
7. 兩組間安排固定3分鐘中性休息並記實際間隔，這是本實驗的流程控制，並非宣稱塔羅需要3分鐘。過程中若已看到結果，仍保留紀錄但不入前向主分析。
8. 賽後以官方或可追溯計分頁核對90分鐘含補時結果；延長賽、PK另存。主指標用同一實際結果評兩組。
9. 核對命中、原始牌面與抽牌程序差異；研究結果按牌源與抽牌條件分組。原判保持原樣，本階段不做解讀錯誤分類或牌義重審。

### 主指標與次指標

| 層次 | 指標 | 固定規則 |
|---|---|---|
| 唯一主要指標 | 同場90分鐘主勝／和局／客勝命中差 | 每組一個主判；備用不補計；不以1/3當所有足球的基準 |
| 棄權處理 | 全收錄樣本命中率＋覆蓋率 | ABSTAIN在主分母中算未命中，另報實際有判場次的命中率，避免靠大量棄權製造高率 |
| 次指標 | 精確比分、總球區間、BTTS、方向信心 | 須賽前獨立填寫；不從賽後敘事轉成命中 |
| 比較基準 | 相同資訊包的無牌判斷或可取得的賽前市場熱門 | 有就並列，沒有則保留此欄空白；不阻擋主要成對比較 |

保持原有解牌方法，解讀是固定的量測步驟。狀態與連結紀錄只針對抽牌前與抽牌操作；原判用於結果核對，不用於本階段解讀機制研究。

### 樣本、統計與判定

- 操作先導30個成對賽事，修資料欄、計時與執行問題；任何修改定版後，另開60對確認區塊，先導不併入其主要p值。
- 確認區塊固定收滿60對才作主要方向推論；中途看執行品質，不因暫時好看而提早宣告。取消、腰斬、日期改變或主要比分無法判定者保留且另報，補足有效成對目標。
- 每場只是一個成對單位，不把兩牌源當兩個獨立比賽；每場每來源只用第一個有效鎖定版本。相同版本的不同區塊分開分析。
- 報手抽命中、網站命中、差距（百分點）、同中／獨中／皆錯、成對bootstrap 95%近似區間、雙尾精確McNemar p。確認區塊唯一主要檢定α=0.05。
- 預先訂實用門檻為手抽至少高10個百分點；這是本專案的行動門檻，並非自然定律。差距達門檻、p<0.05且區間方向支持時，列為本區塊支持；未達則按實際差值與區間寫可支持的範圍，繼續評估機制或操作價值，不把不顯著當相等。
- 60對的規模來自明示假設：手抽75%、網站50%、兩者同中40%、手抽獨中35%、網站獨中10%、皆錯15%；雙尾精確檢定的計算力約80.1%。這是設計情境估算，不保證實際效果或精度。若真差距較小或不一致率不同，確認力也改變。
- 多個機制實驗列探索，各自先導後另開確認；若同時做多項確認，對該確認家族作Holm校正，不從12個假說任挑最漂亮者宣布成功。
- 首個確認區塊若支持差異，再以獨立區塊重現；有關聯不代表已辨明能量、共時性或心理機制。個人結果先只適用Evan與該操作範圍。

## P2：差異出現後，逐項拆解機制

每項先做12場操作探索，先導結果用來安排確認，不當作定論；確認樣本數在看見該項確認結果前按先導不一致率與最小實用差距計算。一次只啟動一個主要介入。

| 次序 | 實驗 | 主要解釋力 | 執行限制與配套 |
|---|---|---|---|
| P2a | 網站既有準備 vs 等時的明確提問／專注準備 | 可否以意念與儀式補回網站表現；同時容許注意力解釋 | 同圖像、同演算法、相同準備時間；由事前隨機分派決定條件 |
| P2b | 網站自動分配牌 vs 本人從已洗好的背面牌池選牌 | 抽取參與是否相關；兩組維持相同展示與解讀方式 | 牌池先以相同演算法固定；記錄選取動作與時間。這是後續介入規格，尚未上線 |
| P2c | 兩種來源匹配放回與正逆位政策 | 現行1＋4與實體習慣是否構成差距 | 不在P1途中改；新版本、新區塊，不能只把實體逆位率硬改50% |
| P2d | 自主決定抽取時刻 vs 同程式預生成 | 操作參與／時刻連結；可同時有自主感解釋 | 兩組同資訊包且相同等待時間，保留生成與揭露時間 |
| P2e | 個人牌 vs 同圖像另一副牌；重問順序與間隔 | 個人牌組連結、熟悉、重問影響 | 使用既有可取得牌具；不要求購買。先固定操作版本再收場次 |
| P2f | 固定原判對原賽事 vs 限制條件內隨機置換賽事 | 既有牌組與原判對指定目標的對應程度 | 不重抽、不重解、不做語義評分；在相近資訊時點／賽事層內置換，保留難度與結果分布差異 |

本階段不做來源標籤遮蔽、同牌換媒介重新解讀或邀請其他解牌者比較。抽牌先後與間隔僅作程序控制，不另設解讀順序偏誤假說。原C02～C04與語義研究保留為暫緩項目，不視為已被排除的原因。

## 靈性方向的解釋架構與來源

Waite《The Pictorial Key to the Tarot》第III部第8節，將明確問題、時間範圍、整體印象與直覺納入其占卜實作；附加實務筆記也提及提問與避免先入為主。[S1] 這提供研究問題的歷史脈絡，並非證明實體牌比數位牌準；本專案也不承接「大牌必然壓過小牌」到球數判定。

《Book T》公開原文把思考問題與切牌列入程序。[S2] 因此「本人參與抽取」可成為研究變項；不能據此宣布網站沒有連結。

榮格《Synchronicity: An Acausal Connecting Principle》提供「共時性」的理論脈絡。[S3] 本專案將主觀意義連結、特定事件對應與比分預測力分開測量；即使主觀連結很強，也須看事前指標是否改善。

Transparent Psi Project相關原始研究示範預登錄、資料稽核與獨立重現。[S4] 2025年的AMP-TPP研究中，探索性異常曾在第二研究確認，但第三研究未重現。[S5] 這些不是足球塔羅研究，也不能替本專案直接判真偽；用來設計「支持、替代解釋、獨立重現」三層證據。

若儀式提高網站表現，可先採用其有效操作，同時保留注意力與靈性機制兩種解釋；若只有實體來源穩定較好，對Evan而言優先使用實體牌仍有實用依據，機制研究繼續；若兩者差距縮小，就查順序、選場與版本，保留最初自述及全部修正。

## 研究輸出與決策路徑

| 觀察到的結果 | 研究結論可以到哪裡 | 實際行動 |
|---|---|---|
| 核心抽樣或牌面保存有可重現錯誤 | 技術缺陷被支持 | 修正後驗證，另開版本；修前修後分帳 |
| 同場同解牌者差距在確認區塊維持 | 兩種操作流程的個人差異被支持 | 保留優勢流程，進入P2辨別機制 |
| 網站加入固定準備後改善 | 準備流程具有操作價值 | 新版本固定準備，再獨立重現；不單獨歸因能量 |
| 本人選取與自動分配的表現不同 | 抽取參與因素值得追蹤 | 保持解讀與展示固定，獨立重現抽取操作條件 |
| 差距未穩定重現 | 本次條件下無法重現原幅度 | 用區間寫清可支持幅度，調整適用條件，不改寫原觀察 |
| 連結感提高但命中未提高 | 有主觀體驗效果，未同時見到預測改善 | 保留體驗紀錄，主績效分開 |

## 檔案、資料契約與執行

- `trial_template.json`：一個真實紀錄的空白契約，未填欄位保持null，不填造假示例。
- `tools/analyze.py`：Python標準函式庫，依實驗／區塊／版本／解牌者／賽事配對，處理棄權、未完賽、重複、時間與結果衝突。
- `tools/audit-draw.cjs`：直接載入已下載的正式原碼做離線抽樣，不改網站。
- `tools/test_analyze.py`：合成輸入的18項計分與資格測試；不列入實績。
- `results/`：本次歷史描述與技術結果；私有原始雲端明細留在使用者資料範圍，不放進公開程式目錄。

```bash
python tools/analyze.py trials.jsonl
python -m unittest discover -s tools -p 'test_*.py' -v
node tools/audit-draw.cjs /path/to/Evan-tarot-lab 100000 > audit.json
```

`analyze.py`輸入每行一個完整紀錄，尚未有結果者actual=null；ABSTAIN是明示棄權。所有時間帶時區，例如`2026-11-07T20:00:00+08:00`。抽牌政策可用`field_reset_then_4`或`one_deck_5_no_replacement`。本工具為新前向資料所寫，舊Sheets資料需先建立對應且不得補造作者。

本版封存方案是保留原始JSON與版本差異；雜湊僅驗一致性，不能單獨作不可竄改或第三方賽前時間證明。新帳本需保留實際建立時間與追加式修訂。實機畫面檢查與寫入新Sheets分頁仍是實作待辦；來源標籤遮蔽與語義評分已移出本階段。
